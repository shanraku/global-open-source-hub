# GitHub repository discovery metadata

Use the following metadata in the repository's GitHub **About** panel. These are recommendations for accurate discovery, not claims of global completeness or security certification.

## Suggested repository description

A growing, human-reviewed directory of useful open-source software, with multi-source discovery, project health and security intelligence.

## Suggested website

https://shanraku.github.io/global-open-source-hub/

## Suggested topics

## Apply in GitHub

1. Open https://github.com/shanraku/global-open-source-hub.
2. In the right-side **About** panel, select the gear/edit control.
3. Paste the description above.
4. Set the website field to the live website URL.
5. Add the topics above, then save.

## Accuracy rules

- Keep the description factual and avoid claims such as “all open-source projects”, “world's largest”, “fully secure” or “certified”.
- Remove any topic that no longer matches the actual repository.
- Revisit topics as supported discovery providers and features change.
- Repository description, website URL and topics are GitHub repository settings; they are not changed by editing README or documentation files.
