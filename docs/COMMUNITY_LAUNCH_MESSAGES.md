# Community launch messages

Use these short introductions when sharing the Hub in communities that allow project announcements. Adapt the wording to the community, disclose that you maintain the project, and do not post repetitive messages.

Canonical repository: https://github.com/shanraku/global-open-source-hub

## English
We're building Global Open Source Hub, a growing directory that helps developers, students and curious learners discover practical open-source software and visit the original source repositories.

We want to make useful projects easier to find, keep information transparent, and welcome corrections and contributions. This is a growing curated directory—not a complete index or a security endorsement.

Explore: https://github.com/shanraku/global-open-source-hub

## Posting checklist
- Read the target community's rules and post only where project sharing is allowed.
- Disclose your maintainer relationship.
- Prefer a relevant category or concrete improvement over a generic promotional post.
- Do not claim endorsement, partnerships, global completeness, security certification or user numbers.
- Do not mass-message members or repost the same text repeatedly.
- Be available to respond to questions and correction requests.
